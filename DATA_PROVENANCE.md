# Data provenance

This document records where every shipped data file came from, which script
produced it, and what may legally be redistributed.

## Redistribution position — read before publishing

**The original Management Plan PDFs are NOT included in this release, and must
not be added to it.** They are third-party documents published by various Dutch
site-management organisations. Their redistribution rights have **not** been
established. This repository ships only *extracted text chunks* and data derived
from them.

> **Open question for the repository owner.** `results/new_chunks/chunks_docling.parquet`
> contains 3,102 verbatim text chunks (roughly 1,000 characters each) extracted
> from those PDFs. This is derived content, not a transformation that removes the
> underlying copyright interest. Publishing it may be defensible as quotation for
> research, but that determination has not been made. **Confirm this is
> acceptable — ideally with TU Delft's legal or RDM office — before making the
> repository public.** If it is not, the chunk text can be replaced with chunk
> IDs plus offsets, which keeps every metric in the paper reproducible for anyone
> who obtains the PDFs independently.

The expert annotations underlying the ground truth are from Cheang et al. and are
published under **CC BY 4.0**, which permits redistribution with attribution.
Attribution is given in the README, the LICENSE and CITATION.cff.

## Upstream inputs NOT shipped

These are read by some scripts but are absent from this bundle, either because
redistribution rights are unclear or because they are large intermediates:

- The 11 Management Plan PDFs (third-party; rights not established).
- `Capstone-Applied-AI-project_12/MP_Embeddings/WG_MPs_mpnet_Embeddings.parquet`
  — precomputed sentence embeddings, the default input to `src/retrieval.py`.
- `Datasets/.../Reference sentences Matching final+Label.xlsx` — the raw 897-row
  sentence-matching file, upstream of `psi_docling.csv`.
- `results/new_chunks/chunks_docling_embedded.parquet` — chunk embeddings
  (regenerable via `src/embed_chunks.py` in the source project).

Because of this, the end-to-end pipeline (PDF to metrics) cannot be re-run from
this repository alone. Everything from the alignment output onward can be. See
the README's reproduction section for exactly which scripts run here.

## Secrets

The LLM judge reads `TUDELFT_TULIP_API_KEY` from a `.env` file. **No `.env` file
and no API key is present in this repository**, and `.env` is listed in
`.gitignore`. The upstream project root contains a real key; it was deliberately
excluded and its presence was verified against the staged tree before committing.
